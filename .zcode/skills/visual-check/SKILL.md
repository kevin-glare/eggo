# Проверка UI и сцены Eggo

## Главный принцип: скриншоты IAB не работают

Скриншоты панели Telegram Mini App (in-app browser) не рендерятся без фокуса
окна — полагаться на них нельзя. Вместо них:

- **Вёрстка — геометрией DOM**: `getBoundingClientRect` элементов
  (высоты, выход за вьюпорт, перекрытия). Экран должен влезать в `100dvh`
  без скролла: резиновая сцена, чип на траве.
- **Canvas — `getImageData`**: проверить, что по ожидаемым координатам
  рисуются пиксели нужного цвета (небо/море/трава/питомец).
- Эталон: iPhone 17 Pro — сцена 470px без кропа.

## Как проверять локально

1. `npm run dev` (localhost:5173; время ×60 — стадии сменяются быстро).
2. Открыть в браузере через skill `browser-use:control-browser`; в браузере
   вне Telegram всё работает на localStorage, синк и пуши выключаются.
3. DOM-геометрия/`getImageData` скриптом в консоли, не скриншотами.

## Стилистические ограничения (утверждено владельцем)

- Облака — «гребёнка» (ряд плоских дуг), пуфы-клубы отвергнуты.
- Сцена слоями: небо → море → луг; слоты sea/meadow, вода голубая, трава зелёная.
- Логотип — SVG-арка БЕЗ градиентов: белый + золотая «o».
- Небо меняется по локальному времени (`dayCycle.ts`): рассвет → день →
  закат → ночь, палитры интерполируются.
- Яйцо рисуется нейтральной `EGG_PALETTE` — цвет питомца не должен
  «палиться» до вылупления.

## Что проверить на глаз у владельца

Анимации GSAP (сценки действий, торт дружбы) в автоматике не оцениваются —
после геометрической проверки предложить владельцу посмотреть живьём.
