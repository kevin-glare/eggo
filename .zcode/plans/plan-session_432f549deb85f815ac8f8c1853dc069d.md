# Тамагочи — Telegram Mini App (MVP)

## Стек (решено совместно)
React + TypeScript + Vite · питомец — пиксель-арт на Canvas · Vitest · localStorage (+ Telegram CloudStorage) · без бэкенда.

## Ключевое архитектурное правило
**Игровая логика — чистый TypeScript без React и DOM. UI — тонкий слой поверх.**
Что это даёт тебе: поведение игры меняется правкой чисел в одном файле `config.ts`; логика покрыта юнит-тестами без браузера; UI можно переписать, не тронув игру; смерть питомца позже добавится как новое состояние, не переписывая ядро.

## Структура
```
src/
  game/            ← чистое ядро, БЕЗ React (тестируется на 100%)
    types.ts       типы: PetState, Stats, Mood, Stage
    config.ts      ВСЕ числа игры: скорость затухания статов, пороги настроений,
                   время эволюции, коэффициент ускорения времени в dev
    engine.ts      tick(state, dt): затухание статов, настроение, болезнь, эволюция
    actions.ts     feed / play / startSleep / wake / wash — чистые функции
    storage.ts     save/load + catchUp: досчитать реальное время, пока приложение
                   было закрыто (вернулся через день — увидел последствия)
    sprites.ts     пиксельные спрайты (матрицы кадров): стадии × эмоции × анимация
  ui/              ← React-слой
    App.tsx
    PetCanvas.tsx  мост React→Canvas: игровой цикл requestAnimationFrame, тапы по питомцу
    StatsBar.tsx   полоски статов
    ActionsBar.tsx кнопки действий
  telegram.ts      тема/хаптика/CloudStorage; безопасный no-op при запуске в браузере
tests/             Vitest: engine, actions, storage/catchUp
```

## Гейм-дизайн — черновик, числа правь смело
- Стадии: **яйцо → малыш → взрослый**, эволюция по времени жизни
- Статы 0–100: сытость, счастье, энергия, чистота — затухают со временем
- Настроение (счастлив / спокоен / грустит / болеет / спит) = функция от статов; меняется мимика и анимация
- Действия: покормить (+сытость), играть (+счастье, −энергия), спать (энергия растёт со временем), мыть (+чистота)
- Бессмертие (решено); болезнь есть — «болеет» при долгом пренебрежении, лечится заботой. Смерть добавим позже отдельным состоянием
- Оффлайн-время учитывается при загрузке
- В dev-режиме время ×60 — эволюцию видно за минуты

## Этапы — каждый заканчивается коммитом, ты ревьюишь diff
0. **Каркас**: Vite + React + TS, Vitest, .gitignore, README, AGENTS.md (конвенции: TS strict без `any`; логика игры только в `src/game/` без импортов React; всё в `src/game/` тестируется; UI-текст на русском; маленькие осмысленные коммиты)
1. **Ядро + тесты** (TDD: сначала тест, потом реализация)
2. **Спрайты + PetCanvas**: питомец дышит, моргает, меняет эмоции — первая визуальная веха
3. **UI + сохранение**: игра полностью играбельна в браузере

5. **Сессия 2**: деплой HTTPS + бот через BotFather → Mini App в твоём Telegram; опционально — бот-уведомления «питомец голоден»
