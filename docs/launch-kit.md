# Чеклист запуска Eggo (бесплатная дистрибуция)

Практическая часть этапа 1 из `docs/ROADMAP.md`: всё делается руками в Telegram
и на сайтах каталогов. Тексты ниже — готовые к вставке.

## 1. Оформление бота (@BotFather)

Apps Center и каталоги берут описание бота из его профиля, поэтому полный сетап
здесь — это и есть «подача» в Apps Center (отдельной формы у него нет).
Команды отправляются @BotFather; он спросит имя бота, затем текст.

1. **`/setdescription`** — текст, который виден в пустом чате с ботом
   («What can this bot do?»):

   > Eggo — тамагочи прямо в Telegram. Заведи питомца из яйца: назови его,
   > корми, играй, купай и гладь. Он растёт и меняется, а уведомления
   > подскажут, когда проголодался или заскучал. Нажми кнопку меню, чтобы
   > начать 🥚

2. **`/setabouttext`** — короткая строка в профиле бота:

   > Тамагочи в Telegram: вырасти питомца из яйца 🥚

3. **`/setuserpic`** — аватар: логотип-арка (белая с золотой «o») на тёмном
   фоне, PNG 512×512. SVG лежит в `src/ui/CreatePetScreen.tsx` — попроси
   ZCode собрать из него PNG.

4. **Bot Settings → Menu Button** — проверить, что ведёт на адрес мини-аппа
   (GitHub Pages).

5. **Команды (`/setcommands`) пока не ставить**: у бота нет обработчика
   `/help`, мёртвые команды хуже их отсутствия — Menu Button уже открывает
   приложение. Вернуться к этому, когда появится webhook-обработчик
   (можно вместе с рефералкой из этапа 2).

## 3. Сообщества

Тред-анонс в TG-чатах про мини-аппы, indie-разработку и «сделай сам» — учебный
проект, написанный с ZCode, здесь скорее плюс. Шаблон:

> Сделал Eggo — тамагочи для Telegram: заводишь питомца из яйца, кормишь,
> играешь, он растёт и меняет внешность. Пуши напомнят, если он голодный.
> Играется прямо в Telegram, без установки: t.me/<юзернейм_бота>
> Это мой учебный проект, код открыт — расскажу, как устроен, если интересно.

Ссылка на бота ведёт в чат с Menu Button — конверсия видна в метриках.

## 4. После публикации

После каждого поста/каталога смотреть приток:

```bash
npm run worker:metrics
```

— новые игроки по дням, DAU/WAU, удержание, воронка стадий. Так видно, какая
площадка реально работает.
