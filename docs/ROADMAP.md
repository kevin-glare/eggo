# Дорожная карта роста Eggo

Зачем: чтобы игра не осталась у автора и друзей. План утверждён 2026-10-28;
исходная ревизия — одиночное ядро крепкое (стадии, квесты, стрики, гены, сон,
пуши), но виральных механик нет, бот не оформлен, аналитики нет. Хостинг и так
бесплатный и выдержит тысячи игроков — расти будем без новой инфраструктуры.

Всё бесплатно, только русский, процесс обычный: один этап = один коммит.

## Этап 1. Бесплатная дистрибуция + минимальные метрики (~неделя) — в работе

1. Оформление бота в @BotFather: описание, about, аватар, Menu Button.
2. Apps Center: отдельной формы нет — он индексирует бота из профиля,
   поэтому полный сетап из п. 1 и есть «подача».
3. Каталоги и сообщества: tgstat, Telegramic, TDirectory, чаты про мини-аппы.
   Готовые тексты и список — в `docs/launch-kit.md`.
4. Минимальная аналитика без нового стека: SQL-отчёт по прод-базе
   (`npm run worker:metrics`) — приток по дням, DAU/WAU/MAU, удержание,
   воронка стадий, здоровье пушей.
5. Roadmap в репо (этот файл).

## Этап 2. Виральное ядро (~2 недели)

1. Кнопка «Поделиться»: `t.me/<бот>?startapp=ref_<id>` + подпись
   «Мой Eggo жив N дней, стадия такая-то» через штатный share Telegram.
2. Рефералка с наградой обоим: `start_param` из initData → миграция D1
   (`referrer_tg_id`), счётчик приглашённых воркер отдаёт в ответе `/sync`,
   клиент выдаёт награду идемпотентно (флаг в сейве, нормализация старых).
   Милстоуны 1 / 3 / 10 приглашённых — уникальный ген внешности.
3. Экран «Позови друга» + подсказка до первого успеха (`src/ui/hints.ts`).

## Этап 3. Глубина и удержание (~2 недели)

1. Фикс квестов: награда +15 счастья часто клампится в ноль при 100/100 —
   переработать так, чтобы награда всегда имела смысл (решение владельца).
2. Тумблер 🔔 в шапку (спроектирован в плане пушей, ждёт реализации).
3. Сезонное событие №1: праздник + уникальный ген/предмет на 1–2 недели —
   повод вернуться и повод для поста. Детали — отдельным мини-планом.
4. Милстоуны возраста в UI (неделя, месяц...) — дешёвый повод для скриншота,
   синергия с шарингом из этапа 2.

## Этап 4. Ритм продвижения (постоянно)

1. Свой TG-канал: devlog, анонсы, истории питомцев игроков, 1–2 поста в неделю.
2. Кнопка «Написать автору» (deep link в личку владельцу) — канал фидбека.
3. Раз в 2 недели сверяться с `npm run worker:metrics` и решать, куда вкладывать
   следующий спринт (виральность vs контент).
4. Позже, если пойдёт: лидерборд друзей по стрику, английский язык,
   монетизация через Telegram Stars — сознательно вне плана сейчас.

## Как мерим успех

- Приток новых игроков в день (после постов и попадания в каталоги).
- DAU/WAU и удержание 2-го/7-го дня.
- Воронка стадий: как далеко добираются пришедшие.
- Здоровье пушей: доля заблокировавших бота (`bot_blocked`) — отток канала
  удержания.
